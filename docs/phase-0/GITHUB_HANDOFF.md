# GITHUB HANDOFF — Phase 0

## اقدام مالک (اختیاری، نه اجباری برای عبور از Gate)
1. یک Repository private جدید بسازید (نام پیشنهادی: `ibo-platform`).
2. هیچ کدی هنوز اضافه نکنید.
3. در صورت تمایل، این پکیج Phase 0 را در مسیر `docs/phase-0/` همان Repository قرار دهید — این می‌تواند اولین Commit مستند پروژه باشد (Commit message پیشنهادی: `docs: freeze IBO product bible (Phase 0 baseline v0.1)`).

## چیزی که در این مرحله لازم نیست
- Push کد
- Screenshot
- اجرای AI Studio
- اجرای CLINE

## معیار عبور از این بخش
عبور از این Gate به هیچ اقدام GitHub وابسته نیست؛ فقط به تأیید محتوایی مالک (ACCEPTANCE_CHECKLIST.md) وابسته است. آماده‌سازی Repository صرفاً یک قدم مفید و اختیاری است، نه پیش‌نیاز.

## قدم بعدی پس از تأیید Phase 0
Claude فایل‌های Phase 1 را تولید می‌کند: `PHASE_1_PLAN.md`, ساختار دقیق Repository، اولین `CLINE_PHASE_01_EXECUTION_PROMPT.md` برای ساخت اسکلت اولیه (بدون Business Logic)، و معیار GitHub Action مربوط به آن Phase.
